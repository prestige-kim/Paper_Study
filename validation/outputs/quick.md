# 5분 안에 이해하는 ResNet

**읽은 논문:** Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun, *Deep Residual Learning for Image Recognition*, CVPR 2016, pp. 770–778. 제공된 파일은 CVF Open Access 판본입니다. 아래 위치 표기는 인쇄 쪽수와 PDF 파일의 쪽수를 함께 적었습니다. [출처: 제공 PDF 첫 페이지의 제목·저자·판본 안내, PDF 메타데이터]

**한 문장으로:** ResNet은 여러 층이 입력을 통째로 새로 변환하도록 학습하는 대신, **입력에 더할 변화량을 학습하게 만들어 깊은 신경망을 훈련하기 쉽게 하는 방법**입니다. [인쇄 p. 771–772 / PDF pp. 2–3, §1·§3.1]

### 무엇이 문제였나?

층을 더 쌓으면 표현력이 늘어나므로 성능도 좋아질 것 같지만, 일반적인 신경망에서는 깊어질수록 **학습 데이터의 오류까지 커지는 성능 저하 문제(degradation problem)**가 관찰됩니다. 이때 문제는 시험 데이터에서만 성능이 떨어지는 과적합과 다릅니다. 논문은 CIFAR-10의 일반 신경망 20층·56층과 ImageNet의 18층·34층 비교로 이 현상을 보여줍니다. [인쇄 p. 770 / PDF p. 1, Fig. 1·§1; 인쇄 p. 774 / PDF p. 5, Fig. 4]

### 핵심 아이디어는?

원하는 변환을 \(H(x)\)라 하면, 몇 개의 층이 \(F(x)=H(x)-x\)라는 **잔차(residual)**를 학습하게 하고 입력 \(x\)를 지름길 연결(shortcut connection)로 더합니다. 출력은 \(F(x)+x\)가 됩니다. 예를 들어 입력을 거의 그대로 유지하는 것이 좋다면, 복잡한 층들이 항등변환을 배워야 하는 대신 잔차를 0에 가깝게 만들면 됩니다. 이것이 더 쉽게 최적화될 것이라는 설명은 **저자의 가설**이며, 뒷받침하는 근거는 실제 훈련 실험입니다. [인쇄 p. 771–772 / PDF pp. 2–3, Fig. 2·§3.1·식 (1)]

입출력 크기가 같은 항등 지름길에는 추가 학습 파라미터가 없습니다. 크기가 달라질 때에는 0으로 채우거나 학습하는 투영 연결을 씁니다. 따라서 모든 지름길이 항상 비용 없이 추가되는 것은 아닙니다. [인쇄 p. 772–773 / PDF pp. 3–4, §3.2–3.3·식 (2)]

### 무엇을 보여줬나?

| 실험과 평가 조건 | 논문이 보고한 결과 | 의미 |
|---|---|---|
| ImageNet 검증 세트, 10-crop 평가, 추가 파라미터 없는 34층 비교 | 일반 신경망 top-1 오류 **28.54% → ResNet 25.03%** | 동일한 깊이에서 3.51%p 개선. 훈련 오류도 줄어 잔차 학습의 최적화 이점을 지지함. [인쇄 p. 774 / PDF p. 5, Table 2·Fig. 4] |
| ImageNet 검증 세트, 단일 ResNet-152, 최상의 다중 스케일 평가 | top-5 오류 **4.49%** | 매우 깊은 모델에서도 좋은 성능을 얻음. [인쇄 p. 775–776 / PDF pp. 6–7, Table 4·§4.1; 평가 방식은 인쇄 p. 773 / PDF p. 4, §3.4] |
| ImageNet 시험 세트, 서로 다른 깊이의 모델 6개 앙상블, 시험 서버 평가 | top-5 오류 **3.57%** | 대표적인 대회 결과. 위의 단일 모델·검증 결과와 평가 조건이 다름. [인쇄 p. 775–776 / PDF pp. 6–7, Table 5·§4.1] |

오류율은 낮을수록 좋습니다. Top-1은 가장 높은 점수의 예측이 정답이 아닌 비율, top-5는 상위 다섯 예측에 정답이 없는 비율을 뜻합니다.

### 가장 중요한 한계

**깊게 학습할 수 있다는 것과 더 잘 일반화한다는 것은 별개입니다.** CIFAR-10에서 1,202층 모델은 훈련 오류를 0.1% 미만까지 낮췄지만 시험 오류는 7.93%로, 110층 모델보다 나빴습니다. 저자는 이를 과적합으로 해석하며 더 강한 정규화를 후속 과제로 제시합니다. 따라서 “층을 많이 쌓으면 언제나 성능이 좋아진다”는 결론은 이 논문이 뒷받침하지 않습니다. [인쇄 p. 776–777 / PDF pp. 7–8, Table 6·Fig. 6·§4.2]

기억할 점은 세 가지입니다.

- ResNet의 중심은 **입력 + 학습한 변화량**이라는 표현 방식입니다.
- 핵심 실험은 추가 파라미터 없이도 깊은 모델의 훈련 오류를 줄였다는 것입니다.
- 최적화 문제를 완화해도 과적합과 일반화 문제는 따로 남습니다.
