## 먼저 잡을 핵심

**문제:** 일반 신경망(plain network)은 층이 깊어지면 표현력이 커져도 훈련 오류가 오를 수 있습니다. 논문은 이 성능 저하 문제(degradation problem)를 최적화 관점에서 다룹니다. **방법:** 여러 층이 입력에 더할 잔차(residual)를 학습하도록 하고 입력을 지름길 연결(shortcut connection)로 보냅니다. **가장 직접적인 근거:** 같은 깊이·파라미터 수의 34층 ImageNet 모델에서 잔차 연결을 추가하자 검증 top-1 오류가 28.54%에서 25.03%로 내려갔고 훈련 오류도 줄었습니다. **해석:** 깊은 모델의 잠재력을 실제로 학습할 수 있게 만드는 구조적 변경입니다. [인쇄 p. 770–772 / PDF pp. 1–3, §1·§3.1–3.2; 인쇄 p. 774 / PDF p. 5, Table 2·Fig. 4]

## 1. 질문과 기여를 분리해 보기

일반적인 과적합에서는 훈련 데이터에는 잘 맞지만 새로운 데이터에 약합니다. 여기서 저자가 먼저 문제 삼은 것은 **더 깊은 일반 신경망이 훈련 데이터에도 더 못 맞는 현상**입니다. 얕은 모델의 뒤에 항등변환을 추가한 깊은 모델은 이론적으로 얕은 모델과 같은 결과를 낼 수 있으므로, 깊은 모델에서 훈련 오류가 더 커지는 것은 가능한 해가 없어서만은 아니라는 논리입니다. 단, 그 해가 존재한다는 사실과 SGD가 실제로 찾을 수 있다는 사실은 다릅니다. [저자 논리: 인쇄 p. 770–772 / PDF pp. 1–3, §1·§3.1]

저자의 명시적 가설은 원래의 변환을 직접 학습하는 것보다 **입력을 기준으로 한 잔차 변환을 학습하는 편이 최적화하기 쉽다**는 것입니다. 보편적인 수렴을 증명하는 정리를 제시한 논문은 아닙니다. [인쇄 p. 771–772 / PDF pp. 2–3, §1·§3.1]

| 중심 주장 | 직접 근거 | 근거가 말해 주는 범위 |
|---|---|---|
| 잔차 학습이 깊은 일반 신경망의 성능 저하를 완화한다. | ImageNet의 대응 모델 비교: Table 2, Fig. 4. CIFAR-10 깊이 비교: Fig. 6. [인쇄 pp. 774·777 / PDF pp. 5·8] | 훈련 오류와 평가 오류의 방향이 함께 개선됨. 시험한 구조·데이터·훈련 조건에 대한 실험적 지지. |
| 깊이를 크게 늘려 정확도를 높일 수 있다. | ImageNet ResNet-50/101/152: Table 3–4. [인쇄 p. 775 / PDF p. 6] | 시험한 범위에서 개선되지만, 깊이 증가와 계산량 증가도 함께 일어남. 모든 깊이에 대한 보장은 아님. |
| 학습한 표현이 다른 인식 과제에도 도움이 된다. | VGG-16 대신 ResNet-101을 사용하는 Faster R-CNN: Table 7–8. [인쇄 p. 777 / PDF p. 8, §4.3] | 이미지 분류에서 객체 탐지로의 효과를 지지함. 비시각 과제의 효과는 이 논문에서 실험하지 않음. |

## 2. 핵심 수식과 의미

### 입력을 유지하고 변화량을 더한다

몇 개의 층이 구현해야 할 변환을 \(H(x)\), 그 층 묶음의 입력 특징을 \(x\)라 하면 논문은 다음처럼 다시 표현합니다.

\[
F(x):=H(x)-x,\qquad H(x)=F(x)+x.
\]

여기서 \(F\)는 학습할 **특징 변환의 잔차**입니다. 분류기의 오답 수나 손실값을 뜻하지 않습니다. \(H(x)\)를 따로 관측해서 잔차 정답을 만드는 절차를 제시하는 것도 아닙니다. 실제 네트워크는 잔차 분기와 지름길을 합친 출력으로 전체 분류 과제를 학습합니다. [정의·학습 구조: 인쇄 p. 771–772 / PDF pp. 2–3, §1·§3.1–3.2; 마지막 설명은 방법에 대한 분석자 해설]

논문의 기본 블록은 다음과 같습니다.

\[
y=F(x,\{W_i\})+x. \tag{논문 식 1}
\]

- \(x\): 블록으로 들어오는 특징 벡터 또는 특징 맵.
- \(\{W_i\}\): 잔차 분기의 여러 층이 학습하는 가중치. \(i\)는 층의 인덱스.
- \(F(x,\{W_i\})\): 그 가중치로 계산하는 잔차 변환.
- \(y\): 잔차와 지름길을 원소별로 더한 값. 이 판본의 블록은 **덧셈 뒤에 ReLU를 적용**하므로 다음 층으로 가는 값은 \(\sigma(y)\)입니다. \(\sigma\)는 ReLU를 뜻합니다.

입출력 차원이 같아야 \(F+x\)를 직접 더할 수 있습니다. 두 층 예시의 간략한 표기는 \(F=W_2\sigma(W_1x)\)이며, 논문은 여기서 편향을 생략합니다. 실제 구현에서는 합성곱마다 BN을 쓰므로 이 간략식이 모든 구현 연산을 표시하는 것은 아닙니다. [인쇄 p. 772 / PDF p. 3, §3.2·식 (1); Fig. 2는 인쇄 p. 771 / PDF p. 2; BN 위치는 인쇄 p. 773 / PDF p. 4, §3.4]

**직관:** 항등변환에 가까운 결과가 필요하면 \(F\)를 0에 가깝게 학습하면 됩니다. 이는 저자의 최적화 동기이며, Fig. 7의 작은 층 응답이 이를 뒷받침하는 관찰입니다. “항상 잔차가 0이어야 한다”는 조건은 없습니다. [인쇄 pp. 772·777 / PDF pp. 3·8, §3.1·Fig. 7·§4.2]

### 차원이 바뀌면 지름길도 맞춘다

\[
y=F(x,\{W_i\})+W_sx. \tag{논문 식 2}
\]

\(W_s\)는 지름길 분기에서 차원을 맞추는 학습 가능한 선형 투영입니다. 합성곱 네트워크에서는 \(1\times1\) 합성곱으로 구현합니다. 공간 해상도가 줄어드는 구간에는 stride 2를 사용합니다. [인쇄 p. 772–773 / PDF pp. 3–4, §3.2–3.3·식 (2)]

| 선택 | 차원이 바뀌는 구간 | 같은 차원 구간 | 특징 |
|---|---|---|---|
| A | 필요한 채널을 0으로 채움 | 항등 지름길 | 지름길의 추가 학습 파라미터 없음 |
| B | 학습하는 투영 사용 | 항등 지름길 | 깊은 bottleneck 모델에서 채택 |
| C | 학습하는 투영 사용 | 학습하는 투영 사용 | 추가 파라미터·비용 증가 |

[인쇄 pp. 773·775 / PDF pp. 4·6, §3.3·§4.1 “Identity vs. Projection Shortcuts”]

## 3. 모델과 학습 흐름

ImageNet 분류에서는 이미지를 받아 1,000개 클래스에 대한 점수를 출력합니다. 입력의 합성곱·풀링 처리 뒤 여러 잔차 블록을 통과시키고, 전역 평균 풀링(global average pooling)과 전결합층·softmax로 마무리합니다. 각 블록에서는 입력을 잔차 분기와 지름길 분기로 보내고, 두 출력을 더해 ReLU에 전달합니다. 모델 전체는 역전파와 SGD로 처음부터 학습합니다. [인쇄 pp. 771–773 / PDF pp. 2–4, §1·§3.2–3.4·Fig. 3]

**기본 블록:** ResNet-18/34는 두 개의 \(3\times3\) 합성곱으로 잔차를 계산합니다. **Bottleneck 블록:** ResNet-50/101/152는 \(1\times1\)로 채널을 줄이고, \(3\times3\)에서 처리한 다음, \(1\times1\)로 채널을 복원합니다. 비용이 큰 공간 합성곱을 적은 채널에서 수행해 깊이를 늘릴 계산 여지를 만듭니다. Fig. 5의 예시는 256채널 입력을 64채널로 줄였다가 256채널로 복원합니다. [인쇄 p. 775 / PDF p. 6, Fig. 5·§4.1 “Deeper Bottleneck Architectures”; 계산 목적에 대한 마지막 설명은 분석자 해설]

| 모델 | 네 개 잔차 단계의 블록 수 | 블록 형태 | 논문의 FLOPs |
|---|---|---|---|
| 18층 | 2, 2, 2, 2 | 두 합성곱 | \(1.8\times10^9\) |
| 34층 | 3, 4, 6, 3 | 두 합성곱 | \(3.6\times10^9\) |
| 50층 | 3, 4, 6, 3 | 세 합성곱 bottleneck | \(3.8\times10^9\) |
| 101층 | 3, 4, 23, 3 | 세 합성곱 bottleneck | \(7.6\times10^9\) |
| 152층 | 3, 8, 36, 3 | 세 합성곱 bottleneck | \(11.3\times10^9\) |

[인쇄 p. 774 / PDF p. 5, Table 1. 논문은 FLOPs를 multiply-adds 기준으로 설명함: 인쇄 p. 772 / PDF p. 3, §3.3]

논문은 softmax 출력과 SGD 훈련을 명시하지만, **분류 손실의 정확한 수식은 제공 본문에 보고하지 않습니다**. 따라서 위 잔차 식을 목적함수로 읽거나 별도 잔차 손실이 있다고 가정하면 안 됩니다. [인쇄 pp. 772–773·776 / PDF pp. 3–4·7, §3.3–3.4·§4.2]

CIFAR-10 구조의 깊이는 \(6n+2\)입니다. \(n\)은 각 해상도 단계에 배치하는 잔차 블록 수이며 세 단계가 있습니다. 각 블록에 두 합성곱이 있으므로 잔차 단계에 \(6n\)개 층, 첫 합성곱과 마지막 분류층까지 합쳐 \(6n+2\)개 가중치 층이 됩니다. 단계의 특징 맵 크기는 32·16·8, 채널 수는 16·32·64이며, 지름길은 모두 option A입니다. [논문 구조·층수: 인쇄 p. 776 / PDF p. 7, §4.2; 층수를 풀어 쓴 문장은 분석자 해설]

## 5. 핵심 결과와 근거

### 같은 조건의 일반 신경망과 비교

ImageNet **검증 세트의 10-crop top-1 오류율**, 단위 %, 낮을수록 좋습니다. 이 비교의 잔차 모델은 option A이므로 일반 모델에 비해 추가 학습 파라미터가 없습니다.

| 깊이 | 일반 신경망 | ResNet |
|---|---|---|
| 18층 | 27.94 | 27.88 |
| 34층 | 28.54 | 25.03 |

[인쇄 p. 774 / PDF p. 5, Table 2]

**보고 결과:** 일반 모델은 18층보다 34층에서 검증 오류가 크고, Fig. 4의 훈련 오류도 더 큽니다. 잔차 모델은 34층이 18층보다 낮은 훈련·검증 오류를 보입니다. **분석자 해석:** 동일한 깊이 34층의 3.51%p 개선은 지름길 구조의 효과를 가장 직접적으로 보여줍니다. 이 차이는 28.54−25.03으로 계산한 값이며 상대 개선율과 다릅니다. [인쇄 p. 774 / PDF p. 5, Table 2·Fig. 4]

### 더 깊게 만들었을 때

아래는 ImageNet **검증 세트, 10-crop**, 오류율 %, 낮을수록 좋습니다. 50/101/152층은 option B를 사용합니다.

| 모델 | top-1 오류 | top-5 오류 |
|---|---|---|
| ResNet-34 B | 24.52 | 7.46 |
| ResNet-50 | 22.85 | 6.71 |
| ResNet-101 | 21.75 | 6.05 |
| ResNet-152 | 21.43 | 5.71 |

[인쇄 p. 775 / PDF p. 6, Table 3]

**지름길 ablation:** 같은 34층의 top-1 오류는 A 25.03%, B 24.52%, C 24.19%입니다. 학습하는 투영을 추가하면 수치상 이득은 있지만, 파라미터 없는 A도 일반 모델보다 크게 좋습니다. 따라서 투영 자체가 성능 저하 완화에 필수는 아니라는 저자의 해석을 지지합니다. B/C의 이득에는 파라미터 수 증가도 섞입니다. [인쇄 p. 775 / PDF p. 6, Table 3·§4.1]

**대표 성능의 조건:** 단일 ResNet-152는 다중 스케일을 사용하는 최상 평가에서 ImageNet **검증 top-5 오류 4.49%**를 기록했습니다(Table 4). 서로 다른 깊이의 모델 6개를 합친 앙상블은 ImageNet **시험 top-5 오류 3.57%**, 시험 서버 평가를 기록했습니다(Table 5). 5.71%, 4.49%, 3.57%는 같은 모델·동일 평가의 숫자들이 아니므로 서로의 차이를 깊이 효과로 해석하면 안 됩니다. [인쇄 pp. 773·775–776 / PDF pp. 4·6–7, §3.4·Table 3–5·§4.1]

| 1,202층 | 19.4M | 7.93 |

[인쇄 p. 776 / PDF p. 7, Table 6·§4.2]

1,202층의 훈련 오류는 0.1% 미만이지만 시험 오류는 110층보다 큽니다. **보고 결과**는 깊은 모델도 학습 가능하다는 것과 일반화가 더 나빠졌다는 것입니다. **저자 해석**은 작은 데이터에 비해 모델이 지나치게 커 과적합했을 가능성입니다. **분석자 해석**으로는 이 실험이 최적화 개선과 일반화 개선을 구분해야 한다는 강한 예입니다. [인쇄 p. 777 / PDF p. 8, Fig. 6 오른쪽·§4.2 “Exploring Over 1000 layers”]

### 분류 표현이 탐지에 도움이 되는가?

동일한 baseline Faster R-CNN 구현에서 특징 추출 모델을 VGG-16에서 ResNet-101로 바꾼 비교입니다. mAP는 높을수록 좋습니다.

| 평가 데이터·조건 | 지표 | VGG-16 | ResNet-101 |
|---|---|---|---|
| VOC 2007 시험, 학습 표기 07+12 | mAP (%) | 73.2 | 76.4 |
| VOC 2012 시험, 학습 표기 07++12 | mAP (%) | 70.4 | 73.8 |
| COCO 검증 | mAP@.5 (%) | 41.5 | 48.4 |
| COCO 검증 | mAP@[.5, .95] (%) | 21.2 | 27.2 |

[인쇄 p. 777 / PDF p. 8, Table 7–8·§4.3. VOC 학습 표기 07+12·07++12의 상세 구성과 탐지 구현은 부록 미제공으로 이 파일만으로 확인할 수 없음.]

COCO의 mAP@[.5, .95] 개선은 **6.0%p**, 논문이 설명한 상대 개선은 약 **28%**입니다. 저자는 같은 탐지 구현을 사용했으므로 좋은 표현에 따른 개선이라고 해석합니다. 다만 이 비교는 특징 추출 모델의 깊이·구조·계산량도 바꾸므로, 지름길 하나의 효과만 분리한 실험은 아닙니다. [보고 값·저자 해석: 인쇄 p. 777 / PDF p. 8, Table 8·§4.3; 마지막 문장은 분석자 평가]

## 6. 그림을 통해 무엇을 확인했나?

- **Fig. 1·4·6 — 훈련과 평가 곡선:** Fig. 4는 가는 선이 훈련 오류, 굵은 선이 중심 crop 검증 오류입니다. 일반 34층의 훈련 곡선은 일반 18층보다 위에 있고, 잔차 34층은 잔차 18층보다 아래로 내려갑니다. Fig. 6은 점선이 훈련, 굵은 선이 시험 오류이며, 오른쪽에서 1,202층과 110층의 훈련 오류는 낮아도 시험 곡선에는 차이가 남습니다. 이는 “학습이 잘 된다”와 “새 데이터에서 잘 된다”를 구분하는 근거입니다. **Fig. 4 곡선의 검증 프로토콜은 중심 crop이며 Table 2의 10-crop 숫자와 동일 평가가 아닙니다.** [인쇄 pp. 770·774·777 / PDF pp. 1·5·8, Fig. 1·4·6]
- **Fig. 2·3·5 — 구조:** 입력을 우회시켜 덧셈하는 위치, 덧셈 뒤 ReLU, 해상도 변경 지름길, bottleneck의 채널 축소·복원을 확인할 수 있습니다. 이는 방법의 구현 구조를 보여주며 성능 향상 자체의 증거는 별도 실험입니다. [인쇄 pp. 771·773·775 / PDF pp. 2·4·6]
- **Fig. 7 — 층 응답 크기:** 세로축은 BN 뒤·비선형 연산 전 각 3×3 층 출력의 표준편차입니다. 위는 원래 층 순서, 아래는 크기 순으로 정렬한 결과입니다. 잔차 모델의 응답이 일반 모델보다 작고, 더 깊은 잔차 모델의 응답도 대체로 작습니다. 저자는 이를 항등변환을 기준으로 작은 변화를 학습한다는 동기에 대한 지지로 읽습니다. **분석자 평가:** 이는 출력 응답의 관찰이며 최적화 용이성의 인과적 증명이나 기울기 크기의 직접 측정은 아닙니다. [인쇄 p. 777 / PDF p. 8, Fig. 7·§4.2]

## 7. 한계와 열린 질문

**저자가 인정한 한계**

1. **일반화는 무조건 좋아지지 않습니다.** 1,202층 CIFAR-10의 결과가 110층보다 나빠, 강한 정규화와의 결합을 후속 과제로 남깁니다. [인쇄 p. 777 / PDF p. 8, §4.2]
2. **일반 신경망의 최적화 곤란에 대한 정확한 이유는 해결되지 않았습니다.** 저자는 BN 사용 및 정상적인 기울기 크기를 근거로 단순 기울기 소실 가능성이 낮다고 논하며, 매우 느린 수렴 가능성을 추측합니다. 이는 확정된 원인 규명이 아닙니다. [인쇄 p. 774 / PDF p. 5, §4.1·각주 3]
3. **깊은 모델의 학습 비용을 고려해야 합니다.** 저자는 감당할 수 있는 학습 시간 때문에 bottleneck을 사용한다고 설명합니다. 152층의 FLOPs는 34층보다 크므로 “기본 지름길에 파라미터가 없다”를 “모델 전체가 저비용이다”로 읽을 수 없습니다. [인쇄 pp. 774–776 / PDF pp. 5–7, Table 1·§4.1]

**분석자 비판**

- **작은 수치 차이의 안정성:** CIFAR-10 110층은 5회 평균과 표준편차를 보고하지만, ImageNet의 비교 Table 2–4에는 반복 실험 분산이나 신뢰구간이 보고되지 않습니다. 따라서 A/B/C의 작은 차이나 101층과 152층의 차이가 얼마나 안정적인지는 이 자료만으로 판단하기 어렵습니다. [인쇄 pp. 774–776 / PDF pp. 5–7, Table 2–4·6]
- **효과 분리의 범위:** Table 2는 지름길 효과를 비교하기 좋은 통제 실험입니다. 반면 더 깊은 모델과 탐지 비교는 용량·계산량·구조가 함께 바뀝니다. 정확도 증가 전체를 잔차 연결만의 효과로 돌릴 수 없습니다. [인쇄 pp. 774–777 / PDF pp. 5–8, Table 1–3·7–8]
- **재현할 때 남는 정보:** 주요 분류 설정은 보고되지만 정확한 손실식, 난수 시드, 패키지 버전, ImageNet 학습률의 정체 판단 규칙은 제공 본문에 구체적으로 보고되지 않습니다. 특히 탐지 구현은 부록을 참조하므로, 부록이 없는 현재 파일에서는 상세 설정을 검증할 수 없습니다. 이는 전체 출판물에 해당 정보가 없다는 뜻은 아닙니다. [분류: 인쇄 pp. 773·776 / PDF pp. 4·7, §3.4·§4.2; 탐지: 인쇄 p. 777 / PDF p. 8, §4.3]

**열린 질문:** 같은 계산 예산에서 깊이와 폭 중 무엇이 더 유리한가? 1,202층에 강한 정규화를 넣으면 일반화가 얼마나 회복되는가? 잔차 연결의 이득은 어떤 데이터 규모·구조·학습률에서 줄어드는가? 이 질문들은 Table 1의 비용 증가, Table 6의 일반화 저하, warm-up 설정으로부터 도출한 분석자의 후속 질문입니다. [인쇄 pp. 774·776–777 / PDF pp. 5·7–8]

## 8. 이해도 질문

먼저 답을 가리고 자신의 말로 설명해 보세요.

1. 깊은 일반 신경망의 시험 오류가 나빠졌다는 사실만으로 최적화 문제라고 할 수 없는 이유는 무엇인가? 이 논문은 어떤 추가 근거를 제시하는가?
2. \(F(x)=H(x)-x\)가 함수 표현을 바꾼다고 해서 표현 가능한 함수가 반드시 늘어나는가? 저자가 바꾸려는 것은 무엇인가?
3. 항등 지름길과 투영 지름길은 언제 다르게 사용해야 하는가? 투영을 모든 블록에 쓰는 C가 조금 더 좋은 숫자를 보이면 왜 공짜 이득이라고 할 수 없는가?
4. ResNet-152의 top-5 오류 5.71%, 4.49%와 앙상블 3.57%를 그대로 나열해 깊이의 효과를 주장하면 어떤 평가 조건을 놓치는가?
5. 1,202층의 낮은 훈련 오류와 높은 시험 오류를 동시에 설명하려면 어떤 개념을 분리해야 하는가?
6. Fig. 7이 잔차의 작은 변화량이라는 설명을 지지하는 이유와, 그것만으로 최적화 원인을 증명하지 못하는 이유는 무엇인가?
7. 지름길의 효과를 직접 확인하는 실험을 설계한다면 무엇을 같게 유지해야 하는가? 탐지 결과만으로 같은 주장을 할 수 있는가?

### 답과 근거

1. 시험 오류만 나빠지면 과적합일 수 있습니다. 논문은 깊은 일반 모델의 **훈련 오류도 더 높다**는 곡선을 제시해 학습 자체가 어려움을 보여줍니다. [인쇄 pp. 770·774 / PDF pp. 1·5, Fig. 1·4]
2. 저자는 같은 차원에서 원래 변환과 잔차 변환을 표현할 수 있다고 가정하면서, **최적화의 용이성**이 다를 수 있다고 말합니다. 표현력 증가의 정리를 증명한 것이 아닙니다. [인쇄 p. 772 / PDF p. 3, §3.1·각주 2]
3. 차원이 같으면 항등을 더할 수 있고, 차원이 바뀌면 padding 또는 투영으로 맞춰야 합니다. C는 같은 차원에서도 학습하는 투영을 넣어 파라미터·계산량을 늘립니다. [인쇄 pp. 772–773·775 / PDF pp. 3–4·6, 식 (1)–(2)·§3.3·§4.1]
4. 각각 검증 10-crop, 검증 다중 스케일 단일 모델, 시험 서버에서 평가한 6모델 앙상블입니다. 모델 결합과 평가 방식·데이터 분할을 맞추지 않은 차이는 깊이만의 효과가 아닙니다. [인쇄 pp. 773·775–776 / PDF pp. 4·6–7, §3.4·Table 3–5·§4.1]
5. 훈련 데이터에 맞추는 **최적화**와 새 데이터에서의 **일반화**입니다. 매우 깊은 모델은 학습에 성공해도 과적합할 수 있습니다. [인쇄 p. 777 / PDF p. 8, Fig. 6·§4.2]
6. 잔차 모델의 층 응답 크기가 작은 것은 작은 수정이라는 동기와 일치합니다. 하지만 측정 대상은 층 출력의 표준편차이고, 다른 최적화 요인을 통제하거나 인과를 증명한 결과는 아닙니다. [저자 관찰: 인쇄 p. 777 / PDF p. 8, Fig. 7; 인과에 관한 답은 분석자 평가]
7. 깊이·폭·파라미터 수·훈련과 평가 조건을 맞추고 지름길 유무를 비교해야 합니다. Table 2와 Fig. 4가 그에 가깝습니다. 탐지 비교는 backbone 전체를 바꾸므로 지름길만의 효과를 분리하지 못합니다. [인쇄 pp. 774·777 / PDF pp. 5·8, Table 2·Fig. 4·Table 7–8; 실험 설계는 분석자 제안]
